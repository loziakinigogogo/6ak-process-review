# 开发与保留评估

评估包内 [开发任务](cases.json) 时，为技能版本、输入和模型记录摘要，用隔离目录保存输出。给新执行者本技能、任务和原稿，留出 `model.json` 和 `flow.md`。由独立评审者对照原稿和任务的观察项审查表达、证据、流向及缺口。结构验证与语义复核分别记录，允许不同且有依据的阅读分组。

反馈评估在初稿后再提供。评估者先让执行者定位一条明确对象，补充一项现行事实；再给一个可能指向多个对象的“这里”。前者只影响相关陈述及引用，后者应先澄清。若使用报告复制的引用，分别试当前和旧版，记录版本错配如何处理。该部分可以使用同版本的报告作集成测试。评估 B 的语义质量时，以模型、审阅稿和聊天落点为准。

若需要验证泛化能力，在技能版本与评分方法冻结后，请独立评估方提供未参与技能编写的真实文档。覆盖不同领域、组织方式、流程结构和缺失类型。用于修改技能的资料转为开发回归用例，未见能力验证换用新输入。包内调价案例和换写法对照的结论仅覆盖实际测试范围。
