# 活动室预约值班手册

服务台收到预约申请后，值班员先核对人数和时段，再办理相应场地的预约。

| 场地 | 办理方式 |
| --- | --- |
| 青禾室 | 值班员在「青禾排期」登记，保存即确认预约，出具电子回执。 |
| 望山室 | 值班员在「望山日历」登记，保存即确认预约，出具纸质回执。 |
| 云溪室 | 值班员在「云溪预约簿」登记，保存即确认预约，出具电子回执。 |
| 合办厅 | 值班员在「青禾排期」登记后只能提交申请。是否同意由场馆方决定，值班员收到同意答复后才能确认预约。 |
| 西苑室 | 值班员在「望山日历」登记。交接本中“谁确认预约”一栏空白。 |

合办厅常规办理单注明，所有场次都须取得场馆方书面同意，含周末。
周末交班单写明，合办厅周末场次取得场馆方口头同意即可确认。两份办理单均在用。
