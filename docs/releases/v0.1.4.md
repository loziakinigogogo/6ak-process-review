# v0.1.4

流程工作台正式并入 skill。安装包包含本地服务、前端页面和布局资源，业务项目使用 Node.js 22 或更新版本即可运行，无需安装 npm 依赖或访问维护仓库。

## 使用变化

- 「流程图」与「节点内容」作为一级视图；节点内容采用分组目录与单节点工作区，关联阅读支持返回位置，未保存输入按节点保留。
- 原文片段与用户补充统一挂载到节点。「添加材料」只需输入文字，保留原话和版本；生成正文、条件与关系由当前 Agent 对话整理，经候选核对采用后共同更新流程图和正文。
- 页面不直接调用 LLM。节点结果只读，原文在材料区域查看，避免逐条正文重复铺开原文。
- 节点尺寸或流程结构变化后自动整理布局，保留固定位置、阅读视角及显式撤销；修复连接点小数偏差导致的小折返。横纵方向分别保存分组布局。

## 安装和恢复

下载本发布的 `install.cjs`，放到业务项目的 `scripts/update-6ak-process-review.cjs`，手动运行：

```text
node scripts/update-6ak-process-review.cjs --version 0.1.4
node .agents/skills/6ak-process-review/workbench/scripts/workbench.cjs serve --task <已有工作台任务目录>
```

新任务先由 Agent 根据真实资料整理模型，再用 `serve --project <项目目录> --model <模型文件>` 创建。`demo` 仅用于合成示例。已有工作台服务在更新后需要保留输入、停止该任务旧服务，再从当前安装版恢复。

## 兼容与验证范围

内容模型 v1、旧 `pricing-ref:v1`、`pricing-review-batch:v1` 及工作台引用继续兼容。已有正式受管批注任务仍用原 `draft → check → commit` 工具，不隐式转换为工作台任务。任务历史、材料和输入归业务项目所有；安装器继续校验安装副本、保留旧副本，不清理业务任务。

验证包含工具回归、证据与未知/冲突保留、候选版本校验、目录阅读、布局、独立安装包的页面与 Agent 采用闭环。合成验证不等同于跨领域业务语义评估。发布包不包含本地业务知识库、用户报告或测试任务。

本地发布验收：232 项工具测试、21 组工作台浏览器回归、12 组自动布局回归和 5 组独立安装包浏览器验收通过。另用已公开的 v0.1.3 ZIP 创建旧受管任务，再升级到 v0.1.4，核对旧副本、任务逐文件摘要与旧工具状态保持一致，重复安装返回 unchanged。
