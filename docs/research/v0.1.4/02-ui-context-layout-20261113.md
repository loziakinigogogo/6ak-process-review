## 一、交互设计

1. **分组上下文拓展**：分组视图增加直接关联的一层上下游节点，按对象 ID 去重，共享的汇合节点只出现一次。显示可见节点间已有的所有关系，不递归扩展组外节点，不创造业务连线。
2. **分组与组外标识**：节点左上显示组号、组名和固定组色；组外节点额外标“组外”。颜色与导航、详情一致，身份不只依赖颜色。
3. **焦点跳转**：点击当前图中的组外节点保留当前分组，详情提供“转到所属组”。搜索结果已在当前图中时也保留分组。
4. **左侧导航栏浮窗化**：左侧栏移为画布内固定浮窗，平时半透明，hover 或键盘聚焦时不透明。支持收起，窄屏默认收起；拖动与缩放画布不会带动浮窗。
5. **视觉间距紧凑化**：顶栏与画布工具栏分别为 48px、40px。节点内容区 400px，正文 14px，说明框随内容增高，条件和去向就近显示，底部保存栏 75px。

> 分组是阅读范围。默认视口优先保留可读尺寸；“适应当前图”显示本组与全部一层邻居。大组仍需要缩放、平移，不保证所有节点同时位于首屏。
