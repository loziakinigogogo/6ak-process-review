# 0.1.4 工作台修改路线

记录日期为 2026-11-16。当前工作台版本是 `0.1.4-dev.1`。正式 skill 的发布版本是 `0.1.3`。联调入口、数据路径和命令见[工作台说明](../../../workbench/README.md)。

## 已落地

| 阶段 | 决策与当前行为 |
| --- | --- |
| 独立工作台 | 在 `workbench/` 维护流程图、右侧抽屉和本地服务。分组显示本组和一层直接邻居。各图独立保存布局，业务内容按工作版本保存。 |
| 结构调整交给 Agent | 首版曾试用手动新增和接线表单。使用反馈后，将「起草新节点」和「调整连线」作为独立入口。新增活动可以单独提交，衔接待确认时保留问题。在已选的无条件顺序线上明确补一步时，候选核对原线替换及前后影响。用户在抽屉直接订正标题、已有说明和已有条件的文字。 |
| 三条预设和交接预览 | 「按条件或渠道拆分」「拆成连续步骤」「从原文补充节点信息」由右侧抽屉发起。预设带入当前节点或已选连线，生成一条可编辑的任务。预览单列拟处理对象和参考材料，自动带入划选原句，未保存草稿由用户主动勾选。确认后复制任务及版本化引用。工作稿更新时可在原预览重新核对对象和范围。 |
| 候选核对、应用和撤销 | Agent 明示实际改动、证据和上下游影响。用户看过差异并明确确认后，按核对摘要应用整批候选。版本或候选有变化时重新核对和确认。最近一次内容操作可在页面撤销，较早的候选应用可生成反向候选，经核对后应用。完整评审与验收场景见 [07 节点结构编辑评审](07-node-structure-editing-review-20261113.md)。 |
| 卡片、抽屉与来源 | 卡片显示操作说明。注意事项、补充和其他细节放在右侧「细节与补充」，可从卡片打开并在模块内修订。抽屉底部列源文件及 Markdown 行号，合并相邻行段并保留中间缺口和来源性质。 |
| 布局重置 | 「整理当前图」按卡片尺寸重新排版，覆盖当前图的手动坐标。有手动移动时也可用「重置位置」。布局撤销可还原此前的坐标和手动标记，并保留此后发生的手动移动。内容撤销独立。 |
| 流程方向 | 正式入口加入「自动 / 纵向 / 横向」。新任务按画布宽高自动判断，手动选择按分组保存。横向卡片 240px、纵向 200px；坐标、固定点、撤销和视口按分组与方向隔离，切回恢复已有位置。旧任务默认纵向，原布局与引用不迁移、不失效。只读对照页保留，共用生产布局引擎。 |
| 多文本卡片 | 单条最多预览三行。多条按原顺序编号，卡面显示前两条，每条最多两行。存在后续文字时，卡片提供全文入口，直接定位到抽屉的「操作说明」。全文及原序用于阅读、订正和 Agent 选文交接。 |

内容模型继续使用 v1。正式审阅和独立工作台各自按任务路径定位工作稿。既有 `pricing-ref:v1`、`pricing-review-batch:v1` 和工作台引用仍按各自协议读取。

## 接着验证的两项布局问题

1. **已有布局上的卡片碰撞。** 打开旧布局、保存长文或应用候选后，等当前图卡片尺寸稳定再检查矩形交叠，范围包括已显示的组外卡片。建议优先局部挪开自动摆放的卡片。涉及手动位置时，可从现有「整理当前图」处理并撤销。验收时检查无碰撞的图坐标稳定且视口保持可读。
2. **主线、反馈线与分支标签的可读性。** 测试顺序主线沿所选方向推进、反馈线从侧面绕行，以及为不同条件的标签留出独立空间。以「记录调价需求 → 测算目标售价」及文件导入、单条录入两个出口作为最小验收例。

## 实际验证与复现

- 方向切换集成运行了 182 项 `npm test`，并完成类型检查和生产构建。隔离合成任务覆盖自动宽高判断、横纵端口与 240/200px 卡片、分组与方向保存隔离、手动位置、重置/撤销、刷新、保存失败后的重试以及旧任务兼容；只读对照页也已回归。没有把这组界面验证扩大表述为跨业务领域内容评审。
- 回归发现紧邻固定卡片的避障通道可能被端点处理贯穿；仅对已检测到穿过无关节点的备用路线，缩小避障留白重试并再次校验。有效路线保持原样。使用真实路由库分别复现并验证横纵两种方向。
- 手动结构表单首版使用合成模型跑过六个场景，覆盖两路交付、阈值、插入与迁移、复用活动、候选过期及撤销。后续 Agent 交接在桌面和窄屏检查了节点与连线目标、选文、草稿、确认复制和目标刷新。
- 卡片与布局重置阶段运行了 168 项 `npm test`，并在隔离浏览器验收布局重置、撤销、详情修订和来源行号。多文本改动之后运行了类型检查、生产构建及 46 项布局与存储测试，另在隔离浏览器验收全文查看、编辑和选文交接。
- 同一份合成数据下，五条操作的卡片实测高度由 452 px 降到 245 px，单条长文由 367 px 降到 189 px。测量基于缩放前的卡片尺寸。
- 源码 ZIP 复现使用 Node.js 22 或更新版本。解压后运行 `npm ci`，再由使用者运行 `npm run dev:demo -- demo2` 加载内置合成资料。默认 `demo1` 需要本地知识库快照。源码包包含锁文件、测试与合成示例，排除依赖安装目录和本地任务。
