已实现

使用 @tisoap/react-flow-smart-edge 5.0.1 代替同列右绕、回流固定左绕的手写规则。实际节点尺寸参与避障，节点移动和内容尺寸变化后重新计算路线。
使用 elkjs 0.12.1 的 layered + ORTHOGONAL，传入真实节点和标签尺寸、固定连接端口，采用节点坐标、edge sections 折点与标签坐标。5px 画布 Handle 在边界外的半径偏移单独对齐，不丢弃有效 ELK 路线。
主流程方向优先级 100，数据/关联 1，返回 0；控制循环中的方向选择，不修改业务箭头的 from/to。
ELK 库按需加载，优先 Worker，失败时回退本线程。布局结果通过最终几何避障检查，只有仍安全的路线进入缓存，其余由 SmartEdge 重算。

保护手动位置与视图隔离

view.layouts[scopeId] 保存 revision、positions、manualNodeIds、routes 和上一次整理的 previous。
完整流程 scopeId=all，各分组以已有 ID 为键。旧 view.positions 作为兼容基线保留。
当前分组包含本组与一层邻居，同一节点在不同图中的位置互不覆盖。
拖动和方向键移动均保存并固定节点；用户可以在详情解除固定。ELK layered 不原生锁定节点，本实现先计算布局，再精确保留固定节点、调整自动节点避开固定位置，最后重新核对所有路线。
撤销只作用于当前图上一次整理；整理后的手动移动会同步保留在撤销基线中。
布局保存带每组 revision，整理额外校验 modelHash；异步计算不能覆盖新位置或新内容。切组时结果始终使用发起时的 scopeId，不写入新打开的分组。
位置失败后可以重试。待保存位置按工作区放在当前标签页 sessionStorage，刷新可恢复，其他窗口不会把它清空；这不是已落盘保存。
模型更新时移除不再属于原图的待保存位置并提示，防止永久无法重试。
旧任务展示字段以事务迁移，保留旧坐标，从已有 view 历史识别手动修改；业务 workRevision、modelHash 和原协议不变。

界面

工具栏增加“整理当前图”和“撤销本组整理”。固定节点有图钉标记，详情可解除固定。
普通文字修改不触发自动重排。整理后默认围绕选中节点保持可读缩放，原“适应当前图”仍用于全部节点总览。
沿用 oil-ui-pro 的既有工作区风格，并由独立视觉 agent 复核 1440×900 与 390×844 截图，无必须修改项。
节点重叠、空间不足时避障模块可能回退原连线；复杂图不保证零交叉。
