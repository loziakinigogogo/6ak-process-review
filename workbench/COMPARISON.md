# 流程方向对照预览

方向切换已并入 `0.1.4-dev.1` 正式工作台入口；本页继续作为只读效果对照，复用同一布局引擎。需要保存方向选择、手动位置及撤销时，使用[工作台](README.md)。

独立、只读的布局试验入口。默认「自动」：按中央画布实际宽高选择方向，宽大于或等于高时横向，高大于宽时纵向。窗口调整及详情栏展开/收起会重新判断；尺寸稳定 150ms 后更新，只有方向改变才重新排版。手动选择「纵向原版」或「横向对照」后固定该方向，直到重新选择「自动」。

纵向使用快照内已有分组坐标，没有保存坐标时才自动整理。横向卡片宽 240px，纵向保持 200px；内容、字号及条件标签保持一致，横向通过加宽减少文字换行。节点尺寸测量、连线端口与避障布局使用同一宽度。两种方向均可用 82% 等比例或「适应当前图」查看，也可查看节点详情和切换分组。

在仓库根目录运行：

```powershell
node workbench/scripts/compare-layout.cjs --state "<任务目录>/workbench/state.json" --port 4175
```

打开命令打印的本机 `comparison.html` 地址。启动时只读取一次快照，不初始化或迁移原任务；页面及接口不提供写入能力。修改原工作台后，需要重新启动此预览才能比较新快照。窗口内选择、缩放、分组及详情状态仅保留在当前页面。

合成验证与类型检查：

```powershell
node scripts/check-workbench-comparison-browser.cjs
npm run demo:check
npm test
```

浏览器验证在 `.qa/layout-comparison/` 生成独立合成任务、截图和检查记录。正式工作台入口、布局协议及 skill 安装包不受影响。
